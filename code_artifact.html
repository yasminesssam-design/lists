مشروع الأسبوع

كود مشروع "حديقة الزهور الملونة" 🌸

18 سطر كود فقط!
flower_garden.py 
import turtle

t = turtle.Turtle()
t.speed(0)
turtle.bgcolor("lightgreen")  # خلفية الحديقة

# 1. تعريف دالة رسم الزهرة
def draw_flower(color_name):
    t.color(color_name)
    for i in range(8):       # رسم 8 بتلات
        t.circle(30)
        t.left(45)

# 2. استدعاء الدالة لرسم 3 زهور بأماكن وألوان مختلفة
draw_flower("red")          # زهرة حمراء

t.penup()
t.goto(-150, 100)
t.pendown()
draw_flower("purple")       # زهرة بنفسجية

t.penup()
t.goto(150, -50)
t.pendown()
draw_flower("orange")       # زهرة برتقالية

turtle.done()
التشريح التفصيلي

كيف يفكر الكمبيوتر أثناء تشغيل الكود؟ 🧠

1

تجهيز الشاشة

نغير لون الخلفية للون الأخضر الفاتح lightgreen ليصبح شكل اللوحة كحديقة مع جعل السرعة أسرع ما يمكن speed(0).

2

بناء آلة رسم الزهور

الدالة draw_flower(color_name) تأخذ اللون المطلوب وترسم 8 دوائر متداخلة لتكون البتلات.

3

التحرك بدون خربشة!

نستخدم t.penup() لرفع القلم قبل الانتقال للذهاب لمكان جديد goto(x, y) دون رسم خطوط عشوائية.

4

إعادة استخدام الدالة

ببساطة شديدة نغير اسم اللون فقط مثل "purple" لتقوم الدالة بتلوين الزهرة فورًا!

التحدي الأول: زهرة أزرق زاهي

أضف زهرة رابعة لونهـا أزرق "blue" في الزاوية العلوية اليسرى من الشاشة.

مساعدة: احتاج استخدام penup و goto ثم draw_flower.

التحدي الثاني: زهرة بـ 12 بتلة

عدّل التكرار داخل الدالة لتجعل الزهرة تتكون من 12 بتلة بدلاً من 8 (تذكر تغيير زاوية الدوران!).

مساعدة: $360 \div 12 = 30$ درجة!
🚀

مساعدة: ضع size داخل t.circle(size).
